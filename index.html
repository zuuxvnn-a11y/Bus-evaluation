지정 Google 스프레드시트 자동 저장 설정

연결 대상 시트 ID가 코드에 기본 반영되었습니다

요청하신 스프레드시트(1d6E2c-KOIHBzUpLjvUxmSaafp11LfB2kK797lyHUwas)에 자동 저장되도록 아래 스크립트에 시트 ID가 미리 입력되어 있습니다. 웹 앱 URL만 1회 등록하면 이후 입력 시 자동 저장됩니다.

URL을 등록하면 데이터가 추가·수정·삭제될 때마다 시트로 자동 전송됩니다.

전용 Apps Script 코드 (복사해서 붙여넣기) 
function doPost(e) {
  var ss = SpreadsheetApp.openById("1d6E2c-KOIHBzUpLjvUxmSaafp11LfB2kK797lyHUwas");
  var sheet = ss.getSheets()[0];
  var data = JSON.parse(e.postData.contents);
  
  sheet.clear();
  sheet.appendRow(["날짜", "운수사명", "차번", "기사명", "평점", "비고"]);
  
  if (data.records && data.records.length > 0) {
    data.records.forEach(function(r) {
      sheet.appendRow([r.date, r.company, r.busNumber, r.driver, r.rating, r.note]);
    });
  }
  
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

1. 브라우저에서 script.google.com 접속(모바일은 데스크톱 모드) 후 새 프로젝트 생성

2. 기존 내용을 지우고 위 코드를 붙여넣은 뒤 저장 아이콘 클릭

3. 우측 상단 [배포] > [새 배포] > 유형: 웹 앱 / 액세스 권한: 모든 사용자(Anyone) 설정 후 발급된 웹 앱 URL을 위 칸에 붙여넣기
